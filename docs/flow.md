# 流程（唯一定义；改了这里才算改流程）

流程只认这份文件。对话里的说法与它冲突，以它为准。

**启动参数（在准备之前，先问一句就定）**
- **形状**：`--shape single`（单入口：伞 = 1 个根）或 `--shape multi`（多入口：K 个根，默认）。
  形状先定，后面所有步骤按它跑 —— 不让用户等到 agent 跑完一长串才需要拍板。

**两条硬规矩**
- **只读真包、只改副本**：工作区一律是 `prepare` 出的副本（真包只读，副本内 git 化后可回滚）。
  **测试**（开发 SkillWeave、试跑）只在副本上做；**真跑 SkillWeave 本身就是 production 模式，无需批准**。
- **CLI 只做机械的，判断归模型**：能算的（层数、fanout、体积、集合 diff、守恒）工具做；
  要判断的（层名、归属、拆几份、该删还是该留、哪条 description）模型做。

| # | 步骤 | 做什么 | 命令 | 谁判断 | 现状 |
|---|---|---|---|---|---|
| 0 | **形状**（启动参数） | 单入口还是多入口。两形状的账由 `BASELINE.md` 给出（常驻 token / 点击见项数 / 独立可装损失） | `--shape single\|multi` | 用户（一句话） | ✅ |
| 1 | **准备** | 真包只读 → `cp -Rc` 副本 → 副本内 git 化（摘 remote + 起点 commit）→ 量基线 → `BASELINE.md` | `prepare <pack> --shape …` | 无（纯机械） | ✅ |
| 2 | **建树 · 体检 · 推导各层** | 递归展开披露链（L1..Ln）、逐文档过自己那类 cap、根选择层（L0）单列；出口是 `TODO.md` | `disclosure <pack>` | 机械：层数/fanout/超限/悬空/到不了根；模型：层名与归属 | ✅ |
| 3 | **落形状** | 单入口：`collapse --apply --description`；多入口：`propose --apply-group`。改动只在副本，落盘后回读自检 | `collapse` / `propose` | 模型（那条常驻 description、岛名） | ✅ |
| 4 | **派发** | 事实补全（悬空→包内同名候选 · 到不了根→被披露的兄弟 · 超限→行数+二级标题）+ 划批（单位 = **skill 子树**，≤10 skill/批、按条目数平衡）+ 落 prompt + 计数起点 | `dispatch <pack>` | 无（纯机械） | ✅ |
| 5 | **执行** | 子代理**只回提案不写盘** → 校验并落盘：锚点（±3 行逐字）· 白名单（只准改本批文件 + 其父文档）· 豁免规则白名单 · 拆分落盘+披露断言 | `apply <pack> --proposals …` | 模型（改哪句、拆几份） | ⛔ **`apply` 未建** |
| 6 | **复测** | 集合级对账：该消的消了 · 无新增（不是比计数）· external 集合不变 · 拆分守恒。失败 = 整批回滚 + 梯子 R1..R5，且**同一 prompt 不许重派** | `verify <pack> --state … --expect-fixed …` | 无（纯机械） | ✅ |
| 7 | **路由评测** | **只在动了** `description` / 伞体 / `INDEX.md` 时跑：14 题盲判，判据「新 ≥ 旧 且无题从 1.0 掉到 <0.5」 | `judge` + `score` | 判官模型 | ✅ |
| 8 | **交付** | 把副本的改动合回真包 + 更新 README/报告 + 计划落账（真跑即 production，不需额外批准） | `git merge --ff-only` | 无 | ✅ |

**第 5 步之后跑完只读两个文件**：`dispatch/RUN.md`（每批：过了没 · 哪条判据拦的 · 下一级是什么）· `dispatch/PARKED.md`（走完梯子仍不过的，等一条规则）。

**被并入 / 取消的步骤**（历史说明，别再当独立步骤）：
- 「体检」并入第 2 步（树一建好体检就是免费的）。
- 「提动作」= 第 2 步的出口 `TODO.md`，不另立一步。
- 「选形状」**挪到启动参数**（第 0 步）：不让用户等到中途才拍板。
- 「交付需批准」**取消**：真跑本身就是 production 模式。

**为什么第 6、7 步最要紧**：改字符相似度会**反着走**（改写后越像越可能被误判成重复），只有路由评测能判「改完到底变好还是变坏」。
